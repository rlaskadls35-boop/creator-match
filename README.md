# Creator Match

모비데이즈 과제를 작은 단위로 구현하는 Next.js · React · TypeScript 프로젝트입니다.

## 로컬 실행

Node.js 20.9 이상에서 `npm install` 후 `npm run dev`를 실행하고 http://localhost:3000 에 접속합니다. 화면 변경은 개발 서버에 자동 반영됩니다.

## 현재 구현 범위

- 원 단위 예산 입력, 천 단위 쉼표, 빠른 금액 추가
- 10개 카테고리가 펼쳐진 다중 선택 버튼
- 플랫폼 단일 선택: 전체(기본값) / 유튜브 / 인스타그램. 초기화 시 전체로 복귀.
- 팔로워 규모 단일 선택: 나노 1만 미만 / 마이크로 1만 이상 10만 미만 / 매크로 10만 이상
- 필수 입력 검증, 초기화, 반응형 화면
- 항목명과 입력값을 가로로 정렬한 입력 폼. 16px 선택값, 진한 글자, 44px 버튼으로 구성하며 모바일에서는 세로 정렬.

- 조건 확인 시 원본 CSV에 연결된 크리에이터 결과표 표시. 조건에 맞는 결과가 없으면 빈 상태 안내.
- 결과표: 크리에이터 / 플랫폼 / 카테고리 / 평균 진행 예산 / 팔로워 수 / 평균 조회수 / 참여율 / 누적 캠페인 건수 / 광고주 평점. 내부 ID는 노출하지 않음.

예산은 크리에이터 1명의 과거 평균 진행 예산(`avg_campaign_budget_krw`)이 입력 금액 이하인 후보를 찾는 상한입니다. 현재 확정 견적이나 여러 명의 예산 합계를 의미하지 않습니다. 캠페인 이력이 없거나 평균 예산이 0원인 후보는 예산을 확인할 수 없으므로 결과에서 제외하고 인원수를 안내합니다. 빈 평점은 0점 대신 ‘평가 없음’으로 표시합니다.

복수 카테고리는 선택한 항목 중 하나에 해당하면 통과하며, 플랫폼과 팔로워 규모 및 예산 조건을 모두 만족해야 결과에 포함됩니다. 결과는 CSV의 원래 순서를 유지하며 점수 산정이나 추천 순위는 아직 적용하지 않습니다.

입력 조건을 변경하거나 초기화하면 기존 결과가 사라지고, 조건 확인하기를 다시 눌러 갱신합니다. 입력은 현재 화면의 메모리에만 유지되며 새로고침하면 초기화됩니다. 원본 CSV는 수정하지 않았습니다.
