# Creator Match

광고주가 **크리에이터 1명당 예산·카테고리·팔로워 규모**를 입력하면 섭외 후보를 비교하는 웹 프로토타입입니다. 조건에 맞는 후보의 순위와 항목별 점수 계산 과정을 함께 보여줍니다.

지원자: 김태홍

**[실행 페이지 바로가기](https://rlaskadls35-boop.github.io/creator-match/)** · [GitHub 저장소](https://github.com/rlaskadls35-boop/creator-match)

설치 없이 실행 페이지에서 검색과 점수 계산을 확인할 수 있습니다. 일반 검색은 로그인 없이 이용하며, 운영자 임시 계정은 `admin` / `demo1234`입니다.

## 실행 방법

Node.js **22.22.2 이상인 22.x**, **24.15.0 이상인 24.x**, 또는 **26 이상**과 npm이 필요합니다. 잠금 파일에 고정된 의존성의 실행 조건이며, 제출 준비 시 Node.js 26.3.0에서 검증했습니다. 별도 DB 서버·API 키·환경변수는 필요하지 않습니다.

```bash
npm ci
npm run dev
```

터미널에 표시되는 주소에 접속합니다. 기본 주소는 `http://localhost:5173/creator-match/`입니다. `index.html`을 파일로 직접 열지 말고 개발 서버로 실행해 주세요.

```bash
npm test
npm run build
npm run preview
```

배포용 결과는 `dist/`에 생성되며 미리보기 기본 주소는 `http://localhost:4173/creator-match/`입니다. 테스트·개발·빌드 전에 원본 CSV를 검증하고 SQLite를 자동 준비합니다. `npm run db:build`로 같은 작업만 실행할 수도 있습니다.

## 3분 체험

새 브라우저 프로필 또는 사이트 저장값이 없는 상태에서 아래 조건을 입력하고 **크리에이터 찾기**를 누릅니다.

| 플랫폼 / 예산 / 카테고리 / 규모 | 확인할 결과 |
| --- | --- |
| 전체 / 1,500,000원 / 뷰티·패션 / 마이크로 | 이력 있는 후보 6명, 이력 없는 후보 3명. 기본 매칭 점수 1위는 정은매거진77, 표시 점수 76점 |
| 전체 / 500,000원 / 뷰티 / 나노 | 이력 있는 후보 2명, 이력 없는 후보 1명. 후보가 적을 때 조건을 넓히는 선택지 표시 |
| 전체 / 100,000원 / 뷰티 / 나노 | 이력 있는 후보 0명. 조건 하나를 바꾸면 가능한 근접 후보 3명과 신규 후보 1명 표시 |

후보의 **계산 보기**를 누르면 실제 지표, 비교 집단과 등수, 점수 산정식, 반영 비중, 합산 과정을 볼 수 있습니다. 표 제목을 누르면 해당 지표로 정렬하고, 다시 누르면 정렬 방향이 바뀝니다. 검색 조건 변경은 **크리에이터 찾기**를 누를 때 적용됩니다.

일반 사용자는 로그인 없이 검색할 수 있습니다. 운영자 로그인은 `admin` / `demo1234`이며 역할 화면을 시연하는 임시 계정입니다. 운영자는 동일한 검색·계산 화면에 더해 비중을 조절하고 저장할 수 있습니다. 합계가 100%일 때 미리보기가 바뀌며, 저장한 값은 같은 브라우저의 광고주 화면에 다시 진입할 때 적용됩니다. 기존 저장값이 있으면 기본 비중과 결과가 다를 수 있으며, 운영자 화면에서 **기본값 → 비중 저장**으로 되돌립니다.

## 추천 로직과 설계 근거

1. **선별:** 플랫폼, 선택 카테고리 중 하나, 규모, 과거 1건 평균 단가가 예산 이하인지 확인합니다. 예산은 총 캠페인 예산이 아닌 1명당 상한입니다. 과거 단가는 확정 견적이 아닙니다.
2. **비교:** 참여율·평균 조회수·조회당 비용은 같은 규모 안에서, 광고주 평점은 평점이 있는 전체 후보 안에서 상대 점수로 변환합니다. 검색 결과 수가 바뀌어도 각 후보의 항목 점수는 유지됩니다.
3. **합산:** 조회당 비용 40%, 참여율 30%, 평균 조회수 20%, 광고주 평점 10%를 반영합니다. 캠페인 건수는 경험 정보와 정렬 기준으로 제공합니다.
4. **분리:** 이력 없는 후보는 임의의 단가·평점을 채우지 않고 별도 표에 표시합니다. 예산 충족은 미확인이며 종합점수·통합순위를 부여하지 않습니다.
5. **대안:** 이력 있는 후보가 0명이면 조건 하나만 어긋나는 후보 중 점수가 높은 최대 3명과 바꿀 조건을 보여줍니다. 근접 후보도 없으면 조건 변경 안내를 표시합니다.

| 항목 | 비중 | 비교 대상 | 좋은 방향 |
| --- | ---: | --- | --- |
| 조회 1회당 평균 비용 | 40% | 같은 규모에서 비용을 계산할 수 있는 후보 | 낮을수록 |
| 참여율 | 30% | 같은 규모 전체 | 높을수록 |
| 평균 조회수 | 20% | 같은 규모 전체 | 높을수록 |
| 광고주 평점 | 10% | 전체에서 실제 평점이 있는 후보 | 높을수록 |

조회당 비용은 `과거 1건 평균 단가 ÷ 평균 조회수`입니다. 실제 광고의 조회당 비용이나 전환 성과를 예측하는 수치는 아닙니다.

```text
항목 점수 = 100 − [(더 좋은 값을 가진 인원 + 본인을 제외한 동점자 수 ÷ 2)
                  ÷ (비교 집단 인원 − 1) × 100]
매칭 점수 = Σ(항목 점수 × 비중 ÷ 100)
```

항목 점수는 소수 첫째 자리로 반올림합니다. 비교 대상이 1명이면 50점입니다. 합산값으로 정렬하고 화면에만 정수 점수를 표시합니다. 동점은 참여율 내림차순, 크리에이터 ID 오름차순으로 결정합니다.

예를 들어 정은매거진77은 기본 비중에서 `98.3×40% + 25.4×30% + 95.8×20% + 95.1×10% = 75.61점`이며 화면에는 76점으로 보입니다.

규모는 자체 기준으로 **나노 15,000명 미만 / 마이크로 15,000명 이상 100,000명 미만 / 매크로 100,000명 이상**입니다. 현재 데이터에서 각각 101 / 72 / 27명입니다. 업계 공통 표준을 주장하는 기준이 아니라, 주어진 데이터에서 비슷한 규모끼리 비교하기 위한 선택입니다.

### 트레이드오프

- 비용과 반응을 우선한 비중은 기획 가설입니다. 실제 집행·전환 데이터로 학습하거나 최적성을 입증한 값은 아닙니다.
- 백분위는 서로 단위가 다른 지표를 비교하기 쉽지만 원래 수치의 차이 크기는 잃습니다. 실제 값과 계산 근거를 함께 표시합니다.
- 조회수는 자체 항목이면서 비용 계산의 분모이기도 합니다. 도달과 비용을 함께 보려는 선택이지만 조회수가 중복 반영되는 한계가 있습니다.
- 카테고리·플랫폼별로 비교 집단까지 나누면 표본이 너무 작아져, 이 둘은 검색 조건으로 사용합니다. 플랫폼·콘텐츠 특성 차이는 점수에서 완전히 보정하지 못합니다.
- 신규 후보에게 가상의 성과를 부여하지 않는 대신, 이력 후보와 하나의 순위로 비교할 수 없습니다. 실제 견적을 별도로 확인해야 합니다.
- 캠페인 건수는 경험의 양이며 성과의 질과 같지 않아 점수에서 제외했습니다. 평점의 표본 수 보정도 하지 않아 소수 집행 평점의 불확실성은 남습니다.

## 데이터와 구성

원본 `dummy_creators.csv`와 동일한 `data/dummy_creators.csv`를 보존합니다. 둘의 SHA-256은 아래와 같으며, 하나라도 다르면 DB 생성을 중단합니다.

```text
6f139b1a8cac4a7aa0d8034bde2df16ae7c06896ee820eec16ddafbcf2738b8c
```

200명 중 캠페인 이력이 있는 후보는 173명, 이력이 없고 평점이 공란인 후보는 27명입니다. 원본의 BOM·줄바꿈은 파일에서 수정하지 않고 파싱 과정에서 처리하며, 공란 평점은 SQL `NULL`로 저장합니다. SQLite에는 원본 11개 필드와 검증용 메타데이터를 저장하고 규모·비용·점수는 조회 후 계산합니다. 누적 예산을 건수로 나누어 제공된 평균 단가를 덮어쓰지 않습니다.

React 18 · TypeScript · Vite · sql.js(SQLite/WASM)를 사용합니다. 브라우저에서 SQLite를 읽기 전용으로 조회하므로 DB 서버 없이 정적 호스팅할 수 있습니다. 최초 접속 시 SQLite와 WASM 다운로드가 필요합니다. 임시 로그인과 비중은 브라우저 저장소에만 남으며 실제 인증·공유 설정 서버는 없습니다.
